Enhanced Adaptive Low-Light Instance Segmentation

What is EALLIS?

EALLIS (Enhanced Adaptive Low-Light Instance Segmentation) is a research system that detects and segments objects in dark, low-light images where ordinary models fail. It builds on Mask R-CNN with a ResNet-50 backbone and adds adaptive illumination, edge-aware learning, and noise-invariant training so that object boundaries stay accurate even under heavy sensor noise and low contrast.

The model recognises 8 object classes: bicycle, car, motorbike, bus, bottle, chair, diningtable, and tvmonitor. For each detected object it predicts a class label, a confidence score, a bounding box, and a pixel-accurate segmentation mask.
