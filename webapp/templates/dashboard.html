About the Project

🌙 What is EALLIS?

EALLIS (Enhanced Adaptive Low-Light Instance Segmentation) is a research system that extends the "Instance Segmentation in the Dark" framework with custom adaptive modules to significantly improve detection and segmentation accuracy in low-light conditions.

The system builds upon Mask R-CNN with a ResNet-50 backbone, incorporating Adaptive White-balance Downsampling (AWD), Smooth-oriented Convolutional Block (SCB), and Disturbance Suppression Learning (DSL), enhanced with our custom EALLIS illumination and edge-awareness modules.

Research Motivation
🔊

Sensor Noise

Low photon counts at high ISO settings introduce severe shot noise and read noise, destroying fine-grained texture information critical for segmentation.

🌑

Low Contrast

Object boundaries become nearly invisible in darkness. Standard edge detectors fail, making precise mask prediction extremely challenging.

🎨

Color Distortion

White balance shifts and RAW sensor data processing under low-light create unnatural color casts that confuse learned feature representations.

Architecture Overview
🏗️ Synthetic Pipeline with AWD + SCB + DSL
MaskRCNNNoiseInv

AWD (Adaptive White-balance Downsampling): Handles color distortions from RAW sensor processing under varying illumination conditions.

SCB (Smooth-oriented Convolutional Block): Suppresses high-frequency noise while preserving object boundaries critical for segmentation.

DSL (Disturbance Suppression Learning): Dual-branch training that forces the network to learn noise-invariant features by processing both clean and noisy versions.

EALLIS Module: Our custom adaptive illumination + edge awareness module injected at C3/C4 feature stages for enhanced low-light performance.
