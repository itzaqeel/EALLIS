📄 Research Information

Background, methodology, and technical details of the EALLIS research project.

Research Objective

🎯 Objective

To develop an enhanced instance segmentation system capable of accurately detecting and segmenting objects in low-light and nighttime conditions, addressing the significant performance degradation experienced by standard detectors when applied to dark environments.

The project aims to improve upon the "Instance Segmentation in the Dark" (ISiD) baseline by introducing adaptive illumination enhancement and edge-aware learning modules that better preserve object boundaries under extreme noise conditions.

Problem Statement

⚠️ The Challenge

Standard instance segmentation models (e.g., Mask R-CNN) are trained and evaluated primarily on well-lit datasets such as MS-COCO. When deployed in low-light scenarios — nighttime surveillance, autonomous driving at dusk, indoor dim environments — their performance drops dramatically due to:

  • Photon noise: Low light means fewer photons reach the sensor, leading to high signal-to-noise ratios (SNR) in captured images.
  • Loss of texture and edge information: Fine-grained visual cues needed for precise mask prediction become indistinguishable from noise.
  • Color and white-balance shifts: RAW sensor data processing under variable illumination creates domain gaps between training and deployment conditions.
  • Small object degradation: Objects that are already challenging at normal lighting become nearly invisible in darkness.
Dataset Information

📂 EALLIS Dataset

The model is trained and evaluated on a custom low-light instance segmentation dataset containing 8 object classes commonly found in urban nighttime scenes.

Classes (8):

  • 🚲 Bicycle
  • 🚗 Car
  • 🏍️ Motorbike
  • 🚌 Bus
  • 🍾 Bottle
  • 🪑 Chair
  • 🍽️ Diningtable
  • 📺 TV Monitor

Dataset Properties:

  • RAW + RGB paired images
  • Normal and dark exposure variants
  • COCO-format annotations
  • Bounding box + instance mask labels
  • Train / Validation split
Training Methodology

🔧 Synthetic Noise Pipeline & Dual-Branch Training

EALLIS employs a sophisticated training strategy that makes the model robust to low-light noise:

  1. Unprocessing: Clean RGB images are "unprocessed" back to synthetic RAW format, simulating sensor-level data.
  2. Noise Injection: Realistic sensor noise (Poisson-Gaussian) is injected into the clean RAW to create noisy variants.
  3. Dual-Branch Forward: Both clean and noisy versions pass through a shared-weight network. The Disturbance Suppression Loss (DSL) minimizes the feature-level difference between branches, enforcing noise invariance.
  4. Edge-Aware Supervision: An additional edge detection head provides auxiliary supervision to preserve object boundaries under noise.
  5. EALLIS Enhancement: Our custom illumination adaptation module dynamically adjusts feature responses based on local illumination estimates.

Training Configuration:

  • Backbone: ResNet-50 (Caffe pretrained)
  • Neck: FPN (Feature Pyramid Network)
  • Optimizer: SGD (momentum=0.9, weight_decay=1e-4)
  • Learning Rate: 0.01 with step decay at epoch 9
  • Warmup: Linear, 500 iterations
  • Epochs: 12
  • Batch Size: 1-2 (GPU limited)

Loss Components:

  • RPN Classification + Regression Loss
  • RoI Classification Loss
  • Bounding Box Regression Loss
  • Mask Prediction Loss (cross-entropy)
  • Edge Detection Loss
  • Noise Invariance Loss (DSL)
  • Clean-path Instance Segmentation Loss
Model Architecture

🏗️ MaskRCNNNoiseInv Architecture

Key Components:

  • AWD Layers: Adaptive White-balance Downsampling — handles RAW color channel processing
  • SCB Blocks: Smooth-oriented Convolutional Blocks — noise-resilient feature extraction
  • FPN: Feature Pyramid Network for multi-scale detection
  • RPN: Region Proposal Network for object candidate generation

EALLIS Extensions:

  • Illumination Adaptation: Dynamic feature recalibration based on local brightness
  • Edge-Aware Head: Auxiliary branch for explicit boundary supervision
  • Noise Invariance: Shared-weight dual processing enforces robustness
  • Custom Backbone Flags: use_eallis, use_edge for ablation control
Evaluation Methodology

📏 COCO-Style Evaluation

All models are evaluated using the standard COCO evaluation protocol:

  • mAP: Mean Average Precision averaged over IoU thresholds [0.50:0.05:0.95]
  • mAP@50: AP at IoU = 0.50 (lenient matching)
  • mAP@75: AP at IoU = 0.75 (strict matching)
  • mAP_s / mAP_m / mAP_l: AP broken down by object scale (small < 32², medium 32²–96², large > 96²)
  • Evaluation is performed for both bounding box (bbox) and instance segmentation (segm) tasks
